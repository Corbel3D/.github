# Corbel Geometries Inc.

We build **precision synchronization control** for professional 3D & 4D capture —
microsecond-accurate timing between large camera arrays and multi-light systems
(OLAT, spherical-gradient / material capture, volumetric video and digital-human studios).

Over 20 turnkey capture studios delivered across 10+ countries.

## Open source

**Lumenkron** — our open sync-control core: documented protocol, Python SDK, offline sandbox
(develop with no hardware) and reference firmware for the entry-tier controller.

*Public release coming soon.* The package name is already reserved on
[PyPI](https://pypi.org/project/lumenkron/).
